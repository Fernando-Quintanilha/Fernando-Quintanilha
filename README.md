## 🚀 Selected work

Most of my production code is private (company systems and SaaS products), so here is what it does and how it's built.

| Project | What it is | Stack |
|---|---|---|
| **Sales-force app** | Order entry, approvals and admin for field sales, integrated with the ERP API. Own auth, role-based areas, 340+ automated tests, code review and continuous deploy. | Next.js · React · TypeScript · PostgreSQL |
| **Management dashboard** | Finance, inventory and sales indicators behind a serverless BFF that authenticates to the ERP gateway via OAuth, with caching and parallel paginated reads. | Node.js · React · Vercel Functions |
| **TV dashboards** | Live warehouse productivity, driver performance and sales-campaign boards for the shop floor. | React · TypeScript · Vercel |
| **TimeShape** | Scheduling SaaS: professionals publish availability, students book without an account. Google Calendar sync, recurring billing, outbox/inbox, idempotency, OpenAPI, CI. | C# .NET · React · PostgreSQL · Docker |
| **DocSign** | Digital payslip distribution and signing. | .NET · React · PostgreSQL · Redis · MinIO |
| **Agent team dashboard** | Local panel to run and track a team of AI coding agents and their token usage. | Node.js · JavaScript |
